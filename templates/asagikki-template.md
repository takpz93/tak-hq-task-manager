## 🧩 穴埋めテンプレ（コピペして埋める）

```
（①フック：今日 or 最近あった出来事を1文で。あいさつ抜きでいきなり）
__________________________________________

（②背景：その出来事の状況・ディテール。自分の仕事や家族の文脈を少し）
__________________________________________
__________________________________________

そこで思ったんですけど、
（③気づき：一番言いたい本音を「〜なんですよね」で）
__________________________________________

これって、（④たとえ話：牛丼/コンビニ/家族など日常の例で言い換える）
__________________________________________
みたいなものだなと思っていて。

（⑤教訓：だからこそ僕は〜しようと思う、と自分ごとに落とす）
__________________________________________

（⑥前向きな締めの宣言）
__________________________________________
ほんじゃまた！

ーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーー
YouTubeで英語Vlogあげてます！
軽〜く見てみてください！

チャンネル登録と高評価、コメントで応援よろしくお願いいたします！
```

### 超ミニ版（時間がない日・3行メモから）
```
今日（出来事）。
それで（気づき）なんですよね。
（一言の前向き）。ほんじゃまた！
```

## 📚 見本（実記事から・型の確認用）

### 見本1：気づき＋たとえ話型（黄金パターン）
> 出典: [n10b660c8b440] 言われたことをやる人と考える人の差

```
今日はクライアントさんに褒めてもらって、めちゃめちゃ嬉しかった話をしたいと思います。

（…初めて修正なしで「バッチリです」と言ってもらえた経緯…）

ただ、ちょっと思ったことがあって。
じゃあ今回やったことを次からも同じように繰り返せばいいのか？
というと、それは違うんじゃないかなと。

僕の中でいつも意識してることなんですけど、
ゴールはクライアントさんの言うことを守ることじゃないんですよね。
クライアントさんの利益につながる動画を作ることがゴール。

これって、言われたことをやる人と、考える人の差なんじゃないかなと思いました。

（…）
今日は気分がいいので、油断せずにこの状況を続けられるように
また一つ一つやっていきます！
ほんじゃまた！
```
**学べる型**: フック（嬉しい出来事）→「ただ、」で転換 →「〜なんですよね」で核心 → 一般化 → 前向き締め。

### 見本2：本音・弱音 → 反転型
> 出典: [nb7a401e1c083] フリーランスになったら自分が上司

```
最近日記の更新が途絶えていましたが、忙しかったという怠慢です。
そして懺悔すると、最近ものすごくたるんでました、、、

（…筋トレをやめ、部屋が散らかり、貯金が減り…）
負のループとはこのことです。。。

ただ、なにもそんなヘタレ発言をするためにこれを書いてるわけではありません！
（…）今では「もっかい、やってやんぞ！！」という強い気持ちが
ふつふつと湧き上がっています。

さて、色々と面白くなってきました！
この日記もまた再開していきます！
ほんでは、また！
```
**学べる型**: 弱音を正直に出す（「、、、」「。。。」の余韻）→「ただ、」で反転 → 決意で締め。

### 見本3：日常エッセイ・感謝型
> 出典: [n903d5b027010] 前職メンバーと再会

```
先日、前職の人たちとご飯に行ってきました。
（…懐かしさが爆発、業界は変わっても人は変わらなかった…）

独立してから改めて感じるのは、
人との繋がりってやっぱり大事だってこと。
仕事としてそうというのはもちろんなんですけど、
それ以上に、そういう存在がいるだけで
気持ちがすごく安らぐんですよね。
自分の居場所があるな、って感じられるというか。

これは大切にしていきたいなと思うし、
次会う時も「ちゃんと生きてるよ」って
胸を張って言えるように、やっていかないとなって思いました。
ほんじゃまた！
```
**学べる型**: 出来事の情景 → 1〜2文改行のリズム →「〜なんですよね」→ やわらかい決意。

### 見本4：定型あいさつ＋持論展開型
> 出典: [nf5fad1b1fdbe] 296 高収入を手放してフリーランスになった話

```
こんにちは！お元気ですか？？
自由人Takです。
今回は、僕が日々考えていることや起きたことを日記にしていこうと思います。

よく「副業で本業の収入を超えてから独立しよう」なんて声を聞きますよね。
実際、僕もそういう考え方はすごくわかります。

（…年収1000万を捨てた話、「生きてる実感がなかったから」…）

でも、どんな道を選ぶにしても大切なのは、どうしたいのかということだと思います。
俺はこうやって生きたいという考えがないと
どの道を選んでも中途半端になりそうだなと今では思います。
```
**学べる型**: パターンAあいさつ →「〜ますよね」で読者を巻き込む → 具体的な数字 → 決意の時だけ「俺」。

### 見本5：AI生成サンプル（メモ→朝日記の完成イメージ）
> 入力メモ例:「昨日Vlog1本目撮った。緊張した。完璧じゃないけど出すことにした。継続が大事」
> ↓ writing-style.md のルールで生成すると、こうなる ↓

```
昨日、ついにYouTubeのVlog第1本目を撮りました。

カメラの前で一人で喋るのって、思ってた以上に緊張するんですよね。
何回も撮り直して、結局「あれ、最初のやつでよかったかも」ってなる始末で。笑

撮り終わってから一回見返したんですけど、
正直、めちゃめちゃ完璧かと言われると全然そんなことなくて。
噛んでるし、間も変だし、編集前提でもうーんって感じでした。

ただ、それでも出すことにしました。

これって筋トレと一緒だなと思っていて。
1回目から重いバーベルは上がらないし、フォームも汚い。
でもやらないと一生上がるようにならないんですよね。

完璧な1本目を待ってたら、たぶん一生出せない。
だったら、ダサい1本目を出して、2本目で少し良くする。
それを積み重ねるしかないなと。

というわけで、近々アップします。
温かい目で見てもらえたら嬉しいです！
ほんじゃまた！

ーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーー
YouTubeで英語Vlogあげてます！
軽〜く見てみてください！

チャンネル登録と高評価、コメントで応援よろしくお願いいたします！
```
**確認ポイント**: フック→「〜なんですよね」→ 笑 → たとえ話（筋トレ）→「〜なと。」→ 前向き締め＋CTA。
※ このサンプルが実記事と「語尾・リズム・たとえ話の入れ方」で一致しているか、Takさんに確認 → ズレがあれば writing-style.md を微調整。
