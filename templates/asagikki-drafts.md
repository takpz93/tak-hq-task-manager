## ドラフト①：YouTube始めました宣言回（自己紹介＋なぜ浪人として生きるか）

```
ちょっと報告があって、YouTubeを本格的に始めることにしました。

このnoteを読んでくれてる人はなんとなく知ってると思うんですけど、
僕は会社を辞めて、フリーランスとして「自由に生きる」を実験中の31歳パパです。
で、その実験の様子を、今度は映像でも残していこうと思っています。

なんで今さら動画なのか？って話なんですけど、
正直、文章だと伝わらない部分があるなとずっと感じてたんですよね。

朝の空気とか、娘とくだらないことで笑ってる時間とか、
「自由ってこういうことか」って思える瞬間って、
文字にした瞬間にちょっと嘘くさくなる気がして。

これって、旅行の思い出に似てるなと思っていて。
どんなに言葉で「最高だった」って説明しても、
その場の写真や動画を見せた方が一発で伝わったりしますよね。
僕の「浪人生活」も、たぶんそれと同じで。

だから、うまく喋れなくても、編集がショボくても、
とりあえず"そのままの自分"を映していこうと思っています。

正直めちゃめちゃ緊張するし、登録者だってまだ数人です。笑
でも、完璧になってから始めようとしたら、たぶん一生始められないんですよね。

なので、この開設までの舞台裏も、失敗も全部、
この朝日記に書いていこうと思います。
よかったら、産まれたてのチャンネルの成長を一緒に見守ってもらえたら嬉しいです。
ほんじゃまた！

ーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーー
YouTubeで〈チャンネルの一言説明〉あげてます！
軽〜く見てみてください！

チャンネル登録と高評価、コメントで応援よろしくお願いいたします！
```

## ドラフト②：登録者◯人のリアル（数字を正直に見せる本音回）

```
今日はちょっと恥ずかしい数字の話をします。

YouTubeを始めたって先日書いたんですけど、
今の登録者数、〈5〉人です。笑
しかもそのうち何人かは、たぶん友達と家族。

普通だったら、こんな数字わざわざ言わないですよね。
カッコ悪いし、「うわ、伸びてないじゃん」って思われるかもしれない。

でも僕、この数字を逆に全部見せていこうと思ってるんですよね。

なんでかっていうと、後で振り返った時に
「あの人、5人スタートだったのにここまで来たんだ」っていう物語の方が、
僕は見ていて面白いし、勇気をもらえるからで。

これって、漫画の主人公と一緒だなと思っていて。
最初から最強だったら、たぶん誰も応援しないんですよね。
弱くて、負けて、でも諦めない過程があるから、人は続きが見たくなる。

だったら僕も、カッコつけずに〈5〉人からの全部を見せた方が、
よっぽど自分らしいなと。

もちろん、数字に一喜一憂はしないと決めてます。
毎日チェックしてたら、きっと心がもたないので。笑
月に一回、振り返るくらいでちょうどいいなと思っています。

というわけで、これからこの数字がどう動いていくのか、
正直に記録していきます。
〈5〉が来月どうなってるか、自分でも楽しみです！
ほんじゃまた！

ーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーー
YouTubeで〈チャンネルの一言説明〉あげてます！
軽〜く見てみてください！

チャンネル登録と高評価、コメントで応援よろしくお願いいたします！
```

## ドラフト③：note読者へ、押し売りしないお願い回

```
今日は、いつも読んでくれてる人にちょっとしたお願いというか、
正直な気持ちを書こうと思います。

最近YouTubeを始めて、毎回末尾にチャンネルのリンクを貼ってるんですけど、
これ、書きながら毎回ちょっとだけ照れるんですよね。笑

「登録してください！」ってグイグイ言うの、
正直あんまり性に合わないなと思っていて。

僕がやりたいのって、来てくれた人を急かすことじゃないんですよね。
「来るのも自由、去るのも自由」でいいなと思っていて。

これって、近所の縁側みたいなものだなと思うんです。
通りかかった人が、気が向いたらちょっと座って、
お茶でも飲んで、用がなくなったら帰っていく。
そのくらいの距離感が、僕にはちょうどいい。

だから、もし僕の動画やこの日記が、
あなたの一日のどこかで「ちょっとホッとするな」って思える場所になれたら、
それだけで僕は本当に嬉しいんですよね。

その上で、もし「この人の続き、見てみたいな」って思ってもらえたら、
こっそりチャンネル登録してもらえたら、めちゃめちゃ励みになります。
もちろん、見てるだけでも大歓迎です。

押し売りみたいになるのは嫌なので、今日はこのへんで。笑
いつも読んでくれて、本当にありがとうございます。
ほんじゃまた！

ーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーー
YouTubeで〈チャンネルの一言説明〉あげてます！
軽〜く見てみてください！

チャンネル登録と高評価、コメントで応援よろしくお願いいたします！
```
