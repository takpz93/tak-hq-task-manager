# 千勝会 開催 企画案

> **ステータス:** ドラフト v1.0 ／ **作成日:** 2026-07-05 ／ **起案:** COO
>
> **前提（未確定のため仮置き）**
> 実際の目的・規模がまだ確定していないため、本案は最も一般的な想定として
> **「社内の決起会・キックオフ（表彰を含む）／中規模（〜100名・予算〜300万円）」**
> を置いて作成しています。方向性が異なる場合（顧客招待型・周年記念・経営者交流会 等）は、
> 「§8 バリエーション」の該当パターンへ差し替えてください。

---

## 1. コンセプト

**「千勝会（せんしょうかい）」= 千の勝ちを積み上げるチームの祝祭。**

日々の小さな「勝ち（=成果・行動）」を全員で可視化し、称え合い、次の期に向けて士気を一つに束ねる場。
単なる懇親会ではなく、**①称える → ②振り返る → ③決起する** の3幕構成で「参加した全員が翌日から動きが変わる」ことをゴールに置く。

- **一言で:** 成果を祝い、方針を共有し、チームの一体感を最大化する半年〜通期の節目イベント
- **キーメッセージ:** 「一人の百勝より、全員の千勝」

---

## 2. 目的（Why）

| # | 目的 | 達成指標（KPI） |
|---|------|----------------|
| 1 | メンバーの努力・成果を正式に称え、モチベーションを引き上げる | 事後アンケートの満足度 4.0/5.0 以上 |
| 2 | 次期の方針・目標を全社で共有し、認識を揃える | 「次期目標を理解できた」回答 90% 以上 |
| 3 | 部署横断の交流を生み、心理的距離を縮める | 「他部署の人と話せた」回答 70% 以上 |
| 4 | 会社の一体感・帰属意識を高め、離職を抑制する | eNPS の前回比プラス |

## 5. 表彰設計（“千勝”を体現する軸）

数字の大きい人だけでなく、**プロセス・貢献・成長**も称えることで「全員が主役」を演出する。

| 賞 | 対象 | 選定方法 |
|----|------|----------|
| MVP賞 | 期の最も顕著な成果 | 定量＋役員評価 |
| ベストチーム賞 | 最も成果を出したチーム | チーム目標達成率 |
| ベストサポート賞（裏方賞） | 縁の下で支えた人 | 全社員投票 |
| ルーキー賞 | 新人・若手の躍進 | マネージャー推薦 |
| ベストチャレンジ賞 | 結果より挑戦を称える | 役員推薦 |
| 千勝賞（特別賞） | “小さな勝ち”を積み続けた人 | 行動ログ／推薦 |

> 副賞は「金額より記憶に残るもの」を推奨（トロフィー＋体験ギフト＋全社共有）。

## 7. 盛り上げ企画（一体感づくり）

- **チーム対抗クイズ**：会社の歴史・数字・メンバー雑学（スマホ投票アプリ利用）
- **成果ウォール**：期中の“勝ち”を付箋/デジタルで貼り出し、来場者が眺められる展示
- **一言リレー動画**：各メンバーの「今期の一勝」を事前収録しダイジェスト上映
- **フォトブース**：ロゴ入り背景＋小道具で撮影 → 後日全社共有

## 8. バリエーション（目的が違う場合の差し替え）

| パターン | 主眼 | 主な変更点 |

| B. 顧客・パートナー感謝会 | 関係強化・受注貢献 | 招待制・受付/導線を丁寧に、代表挨拶と事例紹介を中心に |

| D. 少人数クローズド版 | 濃い対話 | 30名/50万円規模、個室・着席・トークテーマ設計中心 |

## 11. リスクと対策

| リスク | 対策 |
|--------|------|
| 参加率が伸びない | 早期告知・業務時間内開催・上長からの声かけ |
| 進行が押す | 各パートに時間バッファ、司会に巻き権限 |
| 表彰の不公平感 | 選定基準を事前明文化、投票を併用 |
| 予算超過 | 予備費10%確保、内製化オプションを用意 |
| 天候・交通 | 駅近会場、雨天でも導線確保 |
