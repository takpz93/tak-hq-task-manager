# 直近の半導体業界動向メモ（2026年6月時点）

出典：EE Times Japan（https://eetimes.itmedia.co.jp/）ほか各種報道より要約。
記事執筆の背景資料として整理。

## ざっくり言うと
**「AIが半導体を食い尽くしている」**——これが今の業界を貫く一本の軸。

## 押さえておきたい7つの動き
1. **市場が爆発的に拡大**：Gartner予測で2026年の世界半導体市場は前年比 **+63.9%、約1兆3200億ドル** 規模へ。けん引役はAI。
2. **メモリ不足と価格高騰**：AIインフラ構築でDRAM／NANDの構造的な供給不足が深刻化。企業のIT調達コストにも波及。
3. **NVIDIA「Rubin」登場**：2026年に次世代AI向けGPU「Rubin」を出荷予定。AI半導体の主役が世代交代。
4. **製造装置も活況**：2026年Q1の半導体製造装置販売額は **365億ドル超**。最大市場は中国（約110億ドル）。
5. **先端デバイス市場の長期成長**：AIサーバ向けなど先端15品目が2026年見込み157.9兆円 → **2031年224兆円** へ。
6. **次世代3D集積技術**：東京科学大学・WOWアライアンスが高密度集積技術「BBCube」の基盤技術（実装・接続・熱設計）を開発。チップは「積む」時代へ。
7. **AI特需の偏り**：恩恵はメモリ・GPU中心。日本企業や一部分野（スマホ・車載）には届きにくいという指摘も。

## 記事シリーズへの示唆
- 「AIブーム＝半導体ブーム」という一点に絞ると初心者にも刺さる。
- メモリ不足・市場規模の数字は「すごさ」を体感させる素材として使える。
- まだ伸びしろだらけ＝若手・転職層への前向きなメッセージに直結。
