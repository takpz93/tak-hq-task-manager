# はじめてでもわかる半導体 〜第1回：そもそも半導体って、何者？〜

「半導体」って言葉、最近ニュースで毎日のように聞きますよね。でも「で、結局それ何なの？」と聞かれると、案外うまく答えられない。今日はその正体を、できるだけ身近な例えで一緒にほどいていきましょう。

半導体をひとことで言うと、**「電気を流したり止めたりを、超高速で切り替えられる小さなスイッチ」** です。家の電気のスイッチをパチパチするのを、1秒間に何十億回もやっているイメージ。しかも爪の先ほどのチップの中に、そのスイッチが数百億個も詰まっています。想像できます？　東京ドームに人をぎゅうぎゅうに詰めるどころの密度じゃありません。

このスイッチのオン・オフが、コンピューターにとっての「0と1」。つまり、あなたが今スマホで見ているこの文字も、動画も、AIの返事も、元をたどればぜんぶ「スイッチのパチパチ」の集まりなんです。料理でいえば、塩と砂糖みたいなシンプルな素材から、無限のメニューが生まれるのに似ていますね。

ここで、ちょっとワクワクする話を。イーロン・マスク曰く、いま世界中で作られている半導体チップを全部かき集めても、彼がやりたいAI構想にはたった **2%** しか足りていないそうです。

……2%ですよ！？

これだけ世界中で「AIだ」「自動化だ」と大騒ぎして、毎日すごいスピードで未来が来ているように見えるのに、本命はまだ100分の2しか始まっていない。逆に言えば、残りの98%が動き出したら世界はどうなっちゃうの？って、ゾクゾクしませんか。本当にそれが実現したらどうなるか、わくわくしません！？　ちょっと変態ですかね（笑）。

しかもこれ、夢物語じゃないんです。2026年の世界半導体市場は前の年から6割以上も伸びる見込みで、AI向けのメモリは取り合いになるほど足りていない。世界は今、まさにこの「残り98%」を本気で取りに行っている真っ最中です。

半導体業界に入ったばかりの人、これから飛び込もうか迷っている人へ。あなたが今いる場所は、まだ2%の入り口。これほど伸びしろが丸ごと残っているフィールドって、人生でそうそう出会えるものじゃありません。

次回は「なぜ今、世界中がこんなに半導体を奪い合っているのか」を、もっと身近な例えでお話しします。お楽しみに。
