## こちらでブラウザ操作して取る手順

### A. YouTube検索の流入クエリ（過去28日／過去365日）
1. https://studio.youtube.com にチャンネル所有者アカウントでログイン
2. 左メニュー「アナリティクス」→ 上部タブ「リーチ」
3. 「トラフィックソースの種類」カード内の **「YouTube 検索」** の行をクリック（または「詳細」→ 表の「YouTube 検索」行）
4. 右上の期間セレクタで **「過去 28 日間」** を選択 → 表に検索キーワードが視聴回数・構成比つきで並ぶ
5. 表右上の「⋮」または「エクスポート」→ **Google スプレッドシート / CSV** でダウンロード（上位50件以上を取るにはエクスポートが確実）
6. 期間セレクタを **「過去 365 日間」** に変えて同じ操作
7. 「流入先の動画（上位1本）」は、詳細画面で表の左上のセカンダリ指標を「動画」に切り替える（「トラフィックソース: YouTube 検索」を固定したまま「動画」を選ぶ）と、クエリ→動画の内訳が出る。クエリ単位で上位1本を控える

### B. 視聴者が検索しているキーワード（リサーチタブ）
1. 「アナリティクス」→ 上部タブ **「リサーチ」**
2. **「視聴者が検索しているキーワード」** を選択（「YouTube 全体での検索」ではない方）
3. 一覧に「検索ボリューム」（高／中／低 の指標）が表示される。全件を上からコピー、またはスクロールしながら保存

### C. 参考: API で取る場合
YouTube Analytics API は検索クエリ単位の内訳（insightTrafficSourceDetail の YT_SEARCH）を返します。ただしチャンネル所有者の OAuth トークン（scope: `https://www.googleapis.com/auth/yt-analytics.readonly`）が必要です。トークンが用意できれば次のリクエストで取得できます。

```
GET https://youtubeanalytics.googleapis.com/v2/reports
  ?ids=channel%3D%3DUCXAU7ks-wPVoFJykHn08zvA
  &startDate=2026-08-29&endDate=2026-09-25
  &metrics=views
  &dimensions=insightTrafficSourceDetail
  &filters=insightTrafficSourceType%3D%3DYT_SEARCH
  &sort=-views&maxResults=50
Authorization: Bearer <access_token>
```
