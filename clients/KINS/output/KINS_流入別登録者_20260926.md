## 取得するための手順

1. Google Cloud Console で YouTube Analytics API を有効化したプロジェクトの OAuth クライアント（デスクトップ or Web）を用意
2. チャンネル所有者アカウントで scope `https://www.googleapis.com/auth/yt-analytics.readonly` に同意し、アクセストークン（またはリフレッシュトークン）を取得
3. 上記リクエストに `Authorization: Bearer <access_token>` を付けて実行。365日分は `startDate=2025-09-26` に変更
4. 取得したトークンをこの環境の環境変数（例: `YT_ANALYTICS_TOKEN`）として渡していただければ、同じ表形式で出力します。ブラウザで取る場合は、OAuth 2.0 Playground（https://developers.google.com/oauthplayground）で上記 scope を選び、Step 2 で得た access_token を「List possible operations」→ 上記 URL に貼って実行する方法が最短です。

補足: YouTube Studio の UI では「トラフィックソース」ごとの登録者内訳は表示されません（視聴回数・視聴時間のみ）。登録者の流入別内訳は API のみで取得できます。
